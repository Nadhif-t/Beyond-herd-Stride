# Beyond the Herd: STRIDE and simple baselines in a Prosper-calibrated lending marketplace simulator

Replication package for the manuscript *"Beyond the Herd: When Does Exposure Redistribution Reduce Credit Rationing of First-Time Borrowers? STRIDE and Simple Baselines in a Prosper-Calibrated Lending Marketplace Simulator"* (International Journal of Intelligent Engineering and Systems, paper ID 20267291).

Authors: Nazif Tchagafo, Abderrahmane Ez-zahout, Belaid Ahiod (Mohammed V University in Rabat, Morocco).
Contact: ntchagafo@gmail.com


## 1. What this package contains

| Path | Content |
|---|---|
| `simulator/` | Agent-based marketplace simulator and the policies (Hybrid, PopPenalty, UCB-Explore, Quota, NewQuota, ExpCap, STRIDE, STRIDE-uniform, STRIDE-shuffled) |
| `calibration/` | Preprocessing of the Prosper file and calibration of the loan side; calibration of the capital-scarcity parameter τ |
| `configs/` | `tuned.json` (selected configurations), tuning grids, scenario definitions (27), sensitivity ranges, benchmark parameters |
| `analysis/stride_analysis.py` | Post-processing: paired volume margins, equal-volume interpolation with bootstrap, equivalence verdicts, calibration cell statistics, newness overlap, score-quality AUC |
| `outputs/` | Per-replication outcomes behind Tables 3 to 7 and Figs. 2 and 3; realised parameter draws; seed-to-stream mapping |
| `environment/` | Executable environment specification (pinned requirements file or container recipe) |
| `run_all.py` | Entry point |

## 2. Data

## 4. Reproducing the results

Every run is deterministic given its seed. Seed sets are disjoint:

| Purpose | Seeds | Output |
|---|---|---|
| Calibration of τ (Hybrid, 55% of volume) | 900 to 902 | τ = 1.179 (Prosper), 1.026 (benchmark) |
| Hyper-parameter tuning | 101 to 104 | `configs/tuned.json` |
| Main evaluation (13 policies, both calibrations) | 1 to 30 | Tables 3 and 4 |
| Frontiers and equal-volume comparison | 201 to 216 (benchmark 201 to 206) | Fig. 2, Tables 5 and 6 |
| Scenarios (27 configurations) | 301 to 305 | Table 7 |
| Global sensitivity (24 draws) | 400 + 10d + {0, 1, 2}, d = 0 to 23; draw seed 2026 | Fig. 3 |

Random streams: world `(s, 0)`; daily choices `(s, 1000 + t)`; SVD sketch `(s, 5000 + t)`; ExpCap batches `(s, 7000 + t)`. All policies in a replication share the same world and the same 20-day burn-in.

Steps (adapt command names to the final scripts):

```
python calibration/calibrate.py --data data/prosperLoanData.csv      # loan side, Table 2, Fig. 1
python run_all.py --stage tau                                          # seeds 900-902
python run_all.py --stage tune                                         # seeds 101-104, rule below
python run_all.py --stage main                                         # seeds 1-30
python run_all.py --stage frontier                                     # seeds 201-216
python run_all.py --stage scenarios                                    # seeds 301-305
python run_all.py --stage global                                       # 24 draws x 3 replications
python analysis/stride_analysis.py                                     # self-test on synthetic data
```

Tuning rule, identical for all families: maximise the funded share of creditworthy first-time demand (volume-weighted), subject to funded volume of at least 97% of Hybrid. This is a tuning target, not a guaranteed deployment floor; margins on tuning and evaluation seeds are in `outputs/volume_margins.csv`.

## 5. Statistical conventions

- Paired differences against Hybrid over the replications, 95% Student-t intervals, Holm adjustment for the main comparison.
- Equal-volume comparison: linear interpolation of the comparator's mean curve ordered by volume, repeated inside every bootstrap resample; replication indices resampled jointly for all policies and settings; 1,000 percentile-bootstrap resamples; bootstrap seed 0. Comparisons outside the comparator range, or with several crossings, are reported as unresolved. `<AUTHORS TO CONFIRM against the code>`
- Equivalence margin ±2 pp on NPSR (sensitivity ±1 pp): equivalent if the 95% interval lies inside the margin, different if entirely outside, unresolved otherwise.

## 6. Specification of the simulator

The full specification (distributions and ranges of sector affinities, novelty preference and explorer status, initial histories, ticket budgets, loan-size clipping, shrinkage priors, daily event order, capacity and tie handling, SVD folding, content score, quota rounding, impression-cap rules, tuning grids, conversion of cell default rates to latent probabilities) is given in Table 9 of the manuscript and in `configs/`.

## 7. Limits to keep in mind

The investor side is assumed, not identified: the data contain no impressions and no unfunded listings. The evidence concerns first-time borrowers on a consumer marketplace, not SME lending. The adaptive recurrent controller of the earlier manuscript is not implemented here.
